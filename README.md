# :scroll: About

Wheel Hub is a web application designed to simplify the process of searching and managing car wheels. Acting as a powerful filter, the site allows users to search for specific wheels in the catalog based on key information such as rim size, width, bolt pattern (PCD), and finish.

The project also features a dedicated backend for efficient data management, enabling:
- A search API that filters wheels based on user-selected criteria.
- Dynamic image download, which compiles a `.zip` file containing all images of the filtered wheels.
- An upload functionality to update the stock catalog using a PDF file.

## :mag_right: Key Features

- **Advanced Filtering**: Search for wheels by rim size, width, bolt pattern (PCD), finish, and brand.
- **Stock Control**: Filter wheels based on stock quantity in specific locations (São Paulo and Santa Catarina).
- **Batch Image Download**: Download all filtered wheel images in a single `.zip` file for convenience.
- **Stock Upload**: Securely update the wheel catalog by uploading a stock PDF file.
